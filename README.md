# commons-schedule

A simple, open-source scheduling tool for (un)conferences.

## Tech Stack

- Node.js / TypeScript

## Setup

```sh
npm install
```

## Development

```sh
npm run dev      # start the dev server (bind 0.0.0.0 inside the dev container)
npm run build    # production build
npm run lint     # lint
npm test         # run tests
```
